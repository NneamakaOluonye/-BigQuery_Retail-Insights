Data Warehouse Analytics with Google BigQuery & Looker Studio – Cloud Computing Project

Project Overview
This project was part of my MSc coursework in Cloud Computing, where I worked hands-on with Google Cloud Platform (GCP) to explore data warehousing, SQL analytics, and dashboarding. It involved deploying the BigQuery Jump Start Solution, exploring the environment and dataset, writing custom queries, and building new dashboards for visualization.
The main focus of my work was on designing SQL queries to extract insights from a retail dataset and presenting those insights through a custom Looker Studio dashboard connected to BigQuery.  

Tools & Technologies
- Google BigQuery: Cloud Data Warehouse & SQL  
- Looker Studio: Dashboards & Visualization  
- Cloud Run: Simple query interface (output demo only)
- The dataset is called TheLook. It is a fictitious eCommerce clothing site that was created by the Looker team. It is publicly accessible to anyone who has a GCP account and it contains information about customers, products, orders, logistics, web events and digital marketing campaigns.

Tasks:  
1. Explored the BigQuery Data Warehouse
   - Deployed a Jump Start solution on GCP to set up a working warehouse environment.  
   - Familiarized myself with datasets, storage objects, and built-in dashboards.  

2. Designed and Ran Custom SQL Queries to Analyze Spending and Product Trends. 
   - Average Orders by Gender: To compare male vs. female customer spending and find out which gender spends more. 
   - Average Orders by Product Category: To identify which product categories generate the most revenue.  
   - Wrote and tested queries to ensure they returned meaningful, business-ready results.

3. Created Dashboards in Looker Studio to Present Insights in a Business-Friendly Way:
   - Added a new page to the existing dashboard.
   - Showcased customer behavior and product performance using clean, easy-to-read charts.
   - Updated titles and layout to make the dashboard more presentation-ready.
   - The link to the dashboard: [Customer_Order Insights](https://lookerstudio.google.com/u/0/reporting/f4993439-b753-4567-ac6b-e9aa61803c00/page/p_6f1jjus0rd?s=vMSmOS2xwz0)

4. Exposed Queries Through a Cloud Run Service.   
   - As part of the coursework, I deployed a simple Cloud Run Service to allow querying BigQuery tables through a web interface.
